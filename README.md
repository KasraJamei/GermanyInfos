## ۱) پروفایل علمی
- BSc Computer Engineering، IAU Tehran North؛ معدل ۱۷٫۴۳/۲۰ (≈ آلمانی ۱٫۷۷)؛ دیپلم ۱۹٫۱۹ (≈ ۱٫۲۴)؛ فارغ‌التحصیلی ۶ جولای ۲۰۲۵؛ ۱۸۰ ECTS؛ بدون پایان‌نامه لیسانس.
- IELTS 7 (L 8.5, R 6.5, S 7, W 6)؛ بدون GRE و **نمی‌خواهد GRE بدهد**؛ آلمانی تا B1.2 (گواهی دوره، نه Goethe/ÖSD رسمی).
- حدود ۱۹ ماه کار توسعه‌دهنده (سابقه بیمه)؛ از بهمن ۱۴۰۴ فرانت‌اند (Angular) در شرکت خدمات انفورماتیک.
- سه توصیه‌نامه از استادان دانشگاه موجود است؛ ترجمه‌های رسمی آلمانی آماده است، ترجمه رسمی انگلیسی ندارد.
- بودجه: شهریه تا حدود ۴٬۰۰۰ یورو در ترم قابل قبول است، ولی باید برچسب «پولی» داشته باشد. ترجیح: درخواست مستقیم؛ uni-assist قابل قبول است.

## ۲) وضعیت درخواست‌ها (ترم تابستان ۲۰۲۷)
**ارسال‌شده:** Göttingen Applied CS؛ Göttingen Applied Data Science؛ Bonn CS (۳۱ اکتبر، هنوز Received در ۸ نوامبر)؛ Hildesheim International Master in Software Engineering؛ Hildesheim International Master in Data Analytics؛ Freiburg CS؛ Freiburg Embedded Systems Engineering؛ Duisburg-Essen Embedded Systems Engineering؛ Duisburg-Essen Communications Engineering.
**رد شده:** Bonn Cyber Security (۸ نوامبر، Rejected/Excluded؛ دلیل در «View application details»).
**نیمه‌کاره:** Deggendorf Applied CS (فرم و مدارک پر شده؛ ۶۰ یورو پرداخت نشده و ارسال را مسدود کرده)؛ Aalen M.Sc. Machine Learning & Data Analytics (پیش‌نویس؛ VPD لازم است).
**منصرف شده / کنار گذاشته:** RPTU (۶۰ یورو هزینه)؛ TU/e هلند (ترجمه انگلیسی ندارد و مهلت گذشت)؛ Saarland (همه برنامه‌ها GRE می‌خواهند).

## ۴) ردهای مهم و دلیل‌ها
- **GRE لازم (حذف):** TUM، RWTH، Regensburg، Saarland CS/Cybersecurity/Data Science & AI/Embedded/Visual Computing، Kiel UAS، Paderborn، HPI (GRE+VPD)؛ Passau IS → GMAT.
- **شرط پایان‌نامه/آلمانی:** Bonn AI و Mobile Robotics (پایان‌نامه ۱۲ ECTS)، Tübingen (آلمانی C1).
- **Saarland:** راهنمای رسمی (application-guide) می‌گوید مدرک غیر EHEA ⇒ GRE/GATE (از ترم تابستان ۲۰۲۶)، IELTS ≥ 7.0، معدل ≥ 3.0/4 و جزو ۱۰٪ برتر. (اشتباه اولیه‌ی من که «GRE ندارد» اصلاح شد.)
- **Trier:** رقم دوم اعشار معدل را قطع می‌کند (۱٫۷۷ → ۱٫۷). **Bavaria:** فرمول معدل بایرن ۱٫۷۷.
- **TU Darmstadt:** آزمون فقط وقتی مدارک شایستگی را تأیید نکند. **TH Köln:** زمستان ۱ مارس تا ۳۰ آوریل ۲۰۲۷. **Würzburg:** ۱۰ ECTS پایان‌نامه.
- ۱۵ دانشگاه لیست آرینا احمدی‌کیا (TU Darmstadt، Köln، Würzburg، TU Dortmund، Regensburg، MLU Halle، Fulda، Trier، Lübeck، Hof، Koblenz، HS Heilbronn، HS Bochum، HTWK Leipzig، TH Köln) چک شد؛ Bochum و HTWK ماستر انگلیسی کامپیوتر ندارند.
